### Лабораторна робота №2. Системні виклики ядра Linux для роботи з файловими дескрипторами

**Мета:** Навчитися використовувати системні виклики `open`, `read`, `write`, `close` та `lseek` для роботи з файловими дескрипторами, обробляти помилки системних викликів і реалізувати копіювання файлів мовою C.

**Виконані завдання:**
- Створення та компіляція програми для роботи з файловими дескрипторами.
- Використання системних викликів `open`, `read`, `write`, `close` та `lseek`.
- Дослідження зміни позиції читання у файлі за допомогою `lseek`.
- Трасування системних викликів за допомогою `strace`.
- Розробка програми для копіювання файлів блоками по 4096 байтів.
- Перевірка ідентичності скопійованих файлів за допомогою `cmp`.

**Папка роботи:** `lab-02/`

**Середовище:** Ubuntu (WSL), GCC, мова програмування C.

### Лабораторна робота №3. Керування життєвим циклом процесів у C/Linux

**Мета:** Навчитися створювати дочірні процеси за допомогою `fork`, запускати програми через `exec`, очікувати завершення процесів за допомогою `waitpid` та аналізувати їхні статуси завершення.

**Виконані завдання:**
- Створення та компіляція програми для демонстрації роботи `fork`, `exec` та `waitpid`.
- Використання `execlp` для запуску зовнішніх програм `echo` та `ls`.
- Обробка помилок запуску програм за допомогою `perror` та коду завершення `127`.
- Створення кількох дочірніх процесів за допомогою `fork`.
- Аналіз кодів завершення процесів за допомогою `WIFEXITED` та `WEXITSTATUS`.
- Обробка завершення процесу сигналом за допомогою `WIFSIGNALED` та `WTERMSIG`.
- Дослідження завершення дочірнього процесу через `abort()` та сигнал `SIGABRT`.

**Папка роботи:** `lab-03/`

**Файли:** `process_demo.c`, `worker_children.c`.

**Команди компіляції:**
```bash
gcc -Wall -Wextra -pedantic -o process_demo process_demo.c
gcc -Wall -Wextra -pedantic -o worker_children worker_children.c
```

**Середовище:** Ubuntu (WSL), GCC, мова програмування C.

### Лабораторна робота №4. Створення та керування потоками POSIX Threads

**Мета:** Навчитися створювати потоки за допомогою `pthread_create`, передавати потокам аргументи, очікувати їх завершення через `pthread_join` та збирати результати паралельних обчислень.

**Виконані завдання:**
- Створення та компіляція багатопотокової програми з використанням POSIX Threads.
- Використання `pthread_create` для створення потоків та `pthread_join` для очікування їх завершення.
- Передавання аргументів потокам за допомогою структур даних.
- Зміна кількості потоків з 4 до 8 та обсягу обчислень.
- Розрахунок часткових сум та загального результату паралельних обчислень.
- Реалізація паралельного сумування масиву з 100 елементів.
- Дослідження доступу потоків до спільного масиву та запобігання стану гонитви.

**Папка роботи:** `lab-04/`

**Файли:** `threads_demo.c`, `sum_array.c`.

**Команди компіляції:**
```bash

gcc -Wall -Wextra -pedantic -pthread -o sum_array sum_array.c
```

**Середовище:** Ubuntu (WSL), GCC, POSIX Threads, мова програмування C.

- Порівняння результатів трьох алгоритмів на початковому наборі з чотирьох процесів.

### Лабораторна робота №6. Синхронізація потоків м'ютексами та семафорами

**Мета:** Дослідити гонитву даних, навчитися захищати критичні секції за допомогою м'ютексів та обмежувати одночасний доступ потоків за допомогою семафорів.

**Виконані завдання:**
- Створено програму для демонстрації гонитви даних (race condition) між потоками.
- Реалізовано захист спільного лічильника за допомогою `pthread_mutex`.
- Реалізовано обмеження кількості одночасно активних потоків за допомогою POSIX-семафора.
- Проведено тестування програм та зафіксовано результати виконання.

**Результати:**
- `race_demo` — виявлено гонитву даних: отримано 1 475 981 замість очікуваних 4 000 000.
- `race_fixed` — після використання м'ютекса отримано правильний результат: 4 000 000.
- `semaphore_demo` — семафор обмежив кількість одночасно активних потоків до 2.

**Папка роботи:** `lab-06/`

**Файли:**
- `race_demo.c`
- `race_fixed.c`
- `semaphore_demo.c`
- `results.txt`

**Команди компіляції:**

```bash

gcc -Wall -Wextra -pedantic -pthread -o race_fixed race_fixed.c
gcc -Wall -Wextra -pedantic -pthread -o semaphore_demo semaphore_demo.c
```

**Середовище:** Ubuntu (WSL), GCC, C, POSIX Threads, POSIX Semaphores.
